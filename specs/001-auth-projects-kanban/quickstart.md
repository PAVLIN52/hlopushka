# Quickstart: проверка инкремента 001

Это руководство по запуску и ручной проверке фичи от начала до конца. Детали API
описаны в [contracts/](contracts/), модель данных — в [data-model.md](data-model.md).

## Что нужно заранее

- Node.js 24 LTS и npm 11.
- Docker Desktop или OrbStack (Apple Silicon). **На машине его пока нет — установить до
  шага 2.**
- Свободные порты 3000 (фронтенд), 4000 (бэкенд), 5432 (PostgreSQL).

## 1. Установка

```bash
npm install
cp .env.example .env
```

## 2. Запуск всего стека

```bash
docker compose up --build
```

Ожидаемый результат:
- `http://localhost:3000` открывает страницу входа;
- `http://localhost:4000/api/auth/me` отвечает `401`.

## 3. Тесты

Юнит-тесты ООП-ядра (без БД):

```bash
npm run test:core -w backend
```

Ожидаемый результат: все тесты зелёные, в том числе:
- матрица переходов 6×6 для State;
- отмена и повтор через `CommandHistory` с лимитом в 50 шагов;
- исключения `ITERATOR_EMPTY` и `ITERATOR_EXHAUSTED`.

Интеграционные тесты модулей:

```bash
npm run test:e2e -w backend
```

Сквозные сценарии ниже, Playwright:

```bash
npm run test:e2e -w frontend
```

## 4. Ручные сценарии

Подготовка: три браузерных профиля (или обычное окно + окно инкогнито) для пользователей
**Аня** (продюсер), **Боря** (монтажёр) и **Вика** (заказчик).

| # | Действия | Ожидаемый результат | Проверяет |
|---|---|---|---|
| 1 | Аня регистрируется, выходит, входит снова | Видит пустой список проектов | US1, FR-001…005 |
| 2 | Вход с неверным паролем | «Неверный email или пароль» | US1-3 |

| 4 | Боря и Вика регистрируются. Аня добавляет их по email (монтажёр и заказчик). Затем пробует добавить `nobody@x.ru` | Боря и Вика видят проект. Для nobody — «Пользователь не найден…» | US2, FR-008 |
| 5 | Аня пытается сменить свою роль на монтажёра | Отказ `LAST_PRODUCER` | FR-010 |
| 6 | Боря создаёт задачу «Снять интервью» (тип «съёмка», исполнитель Боря, дедлайн вчера) | Карточка в «Препродакшн», помечена как просроченная | US3, FR-013, FR-015 |
| 7 | Доска открыта у Ани и Бори. Боря перетаскивает карточку в «Монтаж» | У Ани карточка переезжает без обновления страницы, меньше чем за 2 с | US4, FR-021, SC-007 |

| 15 | Остановить бэкенд при открытой доске (`docker compose stop backend`), затем запустить снова | Появляется баннер «Нет связи». После запуска бэкенда доска обновляется сразу | FR-022 |
| 16 | Аня удаляет Борю из проекта, пока у него открыта доска | Доска Бори закрывается с сообщением. Его задачи остаются без исполнителя | FR-023, edge cases |
